# Investment Brain Memory Layer

This folder is the GitHub-based long-term memory layer for Bottleneck OS.

## Purpose

ChatGPT Web is responsible for research and reasoning. Codex is responsible for saving, organizing, validating, and updating memory files. GitHub is the durable memory area.

## Workflow

1. ChatGPT Web researches a topic, ticker, market regime, or trade decision.
2. ChatGPT outputs a Brain Note in Markdown.
3. The note is saved into the matching Brain folder.
4. GitHub stores the permanent version history.
5. Future ChatGPT conversations can use these Brain files as context.
6. Website/dashboard export comes later.

## Folder Map

- `Themes/` — theme lifecycle and bottleneck memory.
- `Companies/` — company-level research notes.
- `Market/` — daily/weekly market regime and ETF rotation logs.
- `Watchlists/` — wide list, focus list, daily focus, actual trade candidates.
- `Trade_Journal/` — trade records, lessons, mistake tags, rule updates.
- `Templates/` — standard templates for future notes.
- `Indexes/` — navigational indexes.

## Final Action Labels

Allowed values:

- Buy Candidate
- Probe Candidate
- Watch
- Wait
- Avoid
- Reduce Risk

Research rating does not determine final action. Execution Gate is still required before any actionable trade.
